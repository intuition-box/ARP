## Surprises

- `bun build --env` leaves `process.env.X` in place when `X` is unset, so both builds must always define the variable (empty), or the bundle gains a second run-time name for `ARP_SPONSOR`.
- Bun inlines only dot access (`process.env.X`), not `process.env['X']`.
- A bundle-time-only env var breaks `packages --check` reproducibility once the committed plugin carries a hosted URL; a committed `package.json` setting does not.
- The org namespace `io.github.intuition-box/*` needs an org owner; the user is a member.

## Decisions made

- **Sponsor default as a committed build setting** — `config.sponsorDefault`, one `npm pkg set` to change it. ADR: `.claude/choices/0175-cli-sponsor-default-and-registry-namespace.md`.
- **Registry name `io.github.Wieedze/arp`, case kept** — registry does not fold case; moving to an org later is a new entry. Same ADR.
- **Every failure of the SKILL.md read refuses the name** — on the direct path nobody re-reads it after the planner.
